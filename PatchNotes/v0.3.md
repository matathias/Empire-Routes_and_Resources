## 0.3.5 - Bugfixing
- Date: 2026-07-13
- Type: Minor
- Authors: Matathias

Numerous bugfixes.

### Changes
- Bugfix: route deliveries that hit after loading the game but before a tax cycle would disappear into the void
- Bugfix: in Simple mode, on founding a new settlement, stockpile caps wouldn't be recalculated until after the new-settlement starting resources are granted, meaning that some of those starting resources could be lost to the abyss
- Bugfix: events with a 'convert to silver' option wouldn't actually convert the goods to silver
- Bugfix: when switching from simple to complex mode, the distributed resources could overflow a settlement's stockpile cap and be silently lost
- Bugfix: the settlement cost shown in the new settlement screen could deviate from the settlement cost the game uses to check if the player can afford it
- Bugfix: in simple mode, an event with a stockpile-based multiplier could end up stacking that multiplier against the faction stockpile a number of times equal to the number of settlements involved
- Bugfix: incomplete translation string for Tithe Injection Description

## 0.3.2 - Supply Route Changes
- Date: 2026-07-02
- Type: Minor
- Authors: Matathias

A handful of changes to supply routes (only relevant for Complex mode).

### Changes
- The player can now control how frequently routes are sent out
- Routes now take time to reach their destination, based on the distance and path from the source
- Adds an optional caravan-based route system. When enabled (default off), deliveries are represented by actual world objects that traverse the world map. This can be performance intensive (hence defaulting to off)

## 0.3.1 - Daily Cadence Fixes
- Date: 2026-06-30
- Type: Patch
- Authors: Matathias

Fixes a few issues lingering after the Daily Cadence update.

### Changes
- Separate daily calculations (production, needs, stockpiling) from tax cycle-level calculations (routes, sell orders) in the UI
- Bugfix: rounding issues could create situations where a seemingly maxed-out production allocation slider produced constant clicking noises
